# Ashik Portfolio Website

A free, responsive portfolio built with:
- HTML
- CSS
- JavaScript

## How to use

1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. Edit the placeholder information in `index.html`.
4. Edit colours/design in `style.css`.
5. Edit animations/navigation in `script.js`.

## Important things to update

Search in `index.html` for:
- YOUR_EMAIL@example.com
- YOUR_PHONE_NUMBER
- YOUR PHOTO
- Add project link
- Placeholder

Replace them with your actual information.

## Free hosting

This is a static website, so it can be hosted on GitHub Pages, Cloudflare Pages, Vercel or Netlify without buying traditional web hosting.
